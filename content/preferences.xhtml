Settings are saved as you change them. Highlight generation runs from the Paper skim section in the reader sidebar. Compression ratio A ratio of 10 selects about one sentence per ten candidate sentences. Highlight threshold % Hides highlights whose normalized importance score is below this value. Zero shows every eligible sentence. 100 hides every sentence. The default is 75%. The reader sidebar has the same control for quick changes. Uses embeddings to compare sentences with the generated summary. When this is off, the add-on uses the fast TF-IDF and TextRank baseline. Summary label definitions (TOML) Each label needs a description and a color. Invalid text is not saved. Source Local Ollama Remote API Endpoint API key Summary model Embedding model Leave a model field blank to use the provider default. The embedding model is used only when semantic relevance or summary labels are on. Ollama command sentences per chunk Use map-reduce only when the model context window is too small for the paper.
